# Contributing

Contributions that make Signal Academy clearer, safer, or more accessible are welcome.

1. Create a branch: `git switch -c improve-short-description` (or `git checkout -b ...` on older Git).
2. Make one focused change.
3. Run `.\scripts\Test-Course.ps1` in Windows PowerShell 5.1.
4. Check that examples contain no personal data, secrets, licensed characters, or unsafe system changes.
5. Open a pull request explaining the learner benefit and what you tested.

Course prose uses CC BY 4.0; contributed code uses MIT. By contributing, you agree to those licenses.
