## Visual identity

- Original, high-energy educational superhero print-comic illustration.
- Portrait classroom handout, normally 2:3 aspect ratio.
- Confident black ink contours, crisp cel shading, restrained cross-hatching, halftone dots, and slightly textured off-white paper.
- Saturated navy, cyan, yellow, red, green, purple, and orange spot colours with near-black terminal/code panels.
- Strong hierarchy: dramatic masthead, one short hook, numbered lesson panels, terminal examples, output/result boxes, speech bubbles, tip bursts, and a compact recap strip.
- Dynamic diagonal accents and energy effects may frame content, but must never reduce legibility.
- Friendly, capable heroes; energetic rather than violent or grim.
- Clean code typography. Prefer adding long explanations and code after artwork generation in a layout application rather than relying on generated text.

## Copy/paste page prompt

Replace every item in square brackets. Attach the relevant character-reference sheets.

```text
Use case: scientific-educational
Asset type: portrait educational comic handout for [AGE OR LEVEL] students

Input images:
- Image 1: identity reference for [CHARACTER NAME]
- Image 2: identity reference for [SECOND CHARACTER, IF USED]
Use the references only to preserve our original characters' identity and established series language. Do not redesign them.

Primary request:
Create an original superhero-comic learning handout titled "[EXACT TITLE]" that teaches [LEARNING OBJECTIVE]. The page must make this sequence clear: [CONCEPT 1] -> [CONCEPT 2] -> [CONCEPT 3] -> [RESULT OR RECAP].

Scene/backdrop:
A stylised nighttime technology-city backdrop appears only in the masthead and page-edge accents. Keep the teaching area clean and bright. Use subtle cyan code-energy effects and small original abstract interface motifs.

Characters:
[CHARACTER NAME] demonstrates [ACTION OR CONCEPT]. [SECOND CHARACTER] demonstrates [ACTION OR CONTRAST]. Preserve each referenced face, age, body proportions, hair, mask or glasses, costume construction, crest, and exact colour role. Friendly teaching expressions; natural hands; no fighting pose unless the lesson explicitly requires safe action.

Style/medium:
Original high-energy educational superhero print-comic illustration; confident black ink contours; crisp cel shading; restrained cross-hatching; halftone dots; saturated spot colours; slightly textured off-white paper. It may evoke the broad tradition of energetic print comics, but must not imitate any named artist, publisher, franchise, or existing character.

Composition/framing:
Portrait 2:3 page. Top 22%: dramatic masthead with title and one-sentence hook. Middle 63%: [NUMBER] numbered teaching panels in a clean grid, moving top-to-bottom and left-to-right. Bottom 15%: recap strip with three key takeaways. Reserve generous margins and breathing room. Code cards use near-black backgrounds, high-contrast syntax colours, and monospaced type. Keep every character clear of instructional text.

Panel plan:
1. [PANEL 1 VISUAL + SINGLE TEACHING POINT]
2. [PANEL 2 VISUAL + SINGLE TEACHING POINT]
3. [PANEL 3 VISUAL + SINGLE TEACHING POINT]
4. [PANEL 4 VISUAL + SINGLE TEACHING POINT]
[ADD OR REMOVE PANELS AS NEEDED]

Text (verbatim):
Title: "[EXACT TITLE]"
Hook: "[EXACT SHORT HOOK]"
Panel labels: "[LABEL 1]", "[LABEL 2]", "[LABEL 3]"
Code: "[SHORT VERIFIED CODE ONLY]"
Output: "[EXACT OUTPUT]"
Recap: "[TAKEAWAY 1]", "[TAKEAWAY 2]", "[TAKEAWAY 3]"
Render these words exactly once and add no other text. If the copy is dense, generate the art and empty text boxes first, then typeset the supplied copy separately.

Accessibility and teaching constraints:
- Correct, runnable PowerShell syntax and technically accurate explanations.
- Use New Zealand/British English unless the curriculum says otherwise.
- Reading order must be obvious without relying on colour alone.
- Strong contrast; no tiny body copy; no text over energy effects.
- One concept per panel; examples before edge cases; concise recap.
- Inclusive, classroom-appropriate presentation; practical costumes and anatomy.

Originality and rights constraints:
- Independently original characters and compositions only.
- The word "PowerShell" may appear as necessary factual curriculum text, but do not use or recreate the Microsoft or PowerShell logo, icon, wordmark styling, or trade dress.
- Do not imitate or reference Marvel, DC, any named artist, publisher, superhero franchise, film costume, celebrity, or copyrighted character.
- No third-party logos, trademarks, branded products, watermarks, signatures, or copied catchphrases.
- Use only the original abstract chest crests shown in the supplied character sheets.

Avoid:
copyrighted-character resemblance; official PowerShell logo; franchise-style emblems; photorealism; manga; 3D rendering; grimdark violence; weapons; sexualised anatomy; distorted hands; costume drift; face drift; extra characters; crowded panels; illegible code; invented commands; misspelled text; fake logos; watermarks.
```

## Consistency follow-up prompt

Use this when a generated page changes a character unexpectedly:

```text
Change only the character consistency. Match [CHARACTER NAME] to Image [N]: same face, skin tone, age, hair shape and colour, mask or glasses, build, costume seams, boots, gloves, chest crest, and palette. Keep the page layout, poses, teaching content, code, text boxes, background, lighting, and all other characters unchanged. Do not add any elements.
```

## Recommended workflow

1. Verify the lesson content and PowerShell examples before creating artwork.
2. Attach only the reference sheets for characters used on that page.
3. Generate the page art with short headings and empty body-copy/code areas when possible.
4. Typeset longer explanations and code separately for accuracy and accessibility.
5. Compare the result against the reference sheets. Use the consistency follow-up prompt for one targeted correction at a time.
6. Check that no official logo, recognisable franchise costume, copied catchphrase, signature, or watermark slipped into the result.

This is practical creative guidance, not legal advice. If the series will be sold or widely published, consider a professional intellectual-property review and keep source files and prompt history as evidence of independent development.
